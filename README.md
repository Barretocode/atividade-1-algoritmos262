## Como executar no terminal

### Pré-requisito

É necessário ter um compilador C++ instalado. No Windows, pode ser utilizado o **g++** do MinGW ou do MSYS2.

### Windows (PowerShell)

1. Baixe ou clone este repositório.
2. Abra o PowerShell na pasta onde estão os arquivos `.cpp`.
3. Compile um dos programas, por exemplo:

```powershell
g++ desafio01.cpp -o desafio01.exe
```

4. Execute o programa:

```powershell
.\desafio01.exe
```

5. Digite os valores solicitados pelo programa.

Para executar outro desafio, substitua o número nos dois comandos. Por exemplo, para o Desafio 11:

```powershell
g++ desafio11.cpp -o desafio11.exe
.\desafio11.exe
```

Cada arquivo deve ser compilado e executado separadamente.

### Linux ou macOS

Com o g++ instalado, abra o terminal na pasta do projeto e use:

```bash
g++ desafio01.cpp -o desafio01
./desafio01
```

Substitua `desafio01` pelo nome do desafio desejado.
